# Engineering Learning MCP

A standalone, review-gated engineering knowledge service for Claude Code, Codex and Cursor.

Implementation is being built on a dedicated branch. The service does not depend on any company MCP gateway or agent control plane. All included examples and fixtures are synthetic. No company content, credentials, or production deployments belong in this repository.

Planned core: PostgreSQL with restricted runtime roles; five MCP tools; a separate human review application; versioned, revocable learnings; client configuration templates; automated negative-path tests.

**Status:** under implementation, not approved for shared or production use.
